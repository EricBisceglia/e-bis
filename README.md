# e-bis

My personal CV & Portfolio showcase website.

You can see it [on e-bis.fr](https://e-bis.fr/)

## About

Vanilla HTML, JS, CSS, no dependencies, because why not.

## Installation

1. Clone the project.
2. Copy `data/entries.example.json` to `data/entries.json`.
3. Copy `data/profiles.example.json` to `data/profiles.json`.
4. Give PHP write access to the `data/` directory.
5. Create `images/projects/` for your images.
6. Visit `admin` and start using the project.

The `admin` directory is provided without protection/authentication.
You might want to secure it.
